# AstroTalks Android

Native Android app for personalized AI-generated spiritual conversations.

## Project

- Kotlin + Jetpack Compose
- Google Sign-In only
- Supabase planned for authentication, profiles, chat retention, points, and transactions
- Android package: `com.aarohan.app`

Open the `android-app` directory in Android Studio or build with Gradle:

```bash
cd android-app
gradle assembleDebug
```
